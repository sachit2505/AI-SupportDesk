# Two-Factor Authentication (2FA) Guide

## Setting Up 2FA
Two-Factor Authentication adds an indispensable layer of security to your SupportDesk account. We support Time-based One-Time Password (TOTP) authenticators such as Google Authenticator, Authy, and 1Password:
1. Navigate to **User Profile > Security > Two-Factor Authentication**.
2. Click **"Enable 2FA"**.
3. Scan the provided QR code with your authenticator application.
4. Enter the 6-digit code displayed in your app to confirm pairing.
5. Save your **Backup Recovery Codes** in a secure location.

## Lost Authenticator Device / Recovery Codes
- If you lose access to your phone/authenticator, use one of the 8-digit emergency backup recovery codes generated during setup.
- Each backup code can be used exactly once.
- If you have lost both your authenticator device and your recovery codes, an organization owner or SupportDesk Super Admin must verify your identity via photo ID or video verification before resetting 2FA.
